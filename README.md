# Assistente Didático Inclusivo com Inteligência Artificial Generativa 🧠✨

### 🌟 Sobre o Projeto
Este projeto nasceu da fusão entre a minha vivência prática na Educação Pública como Professora e o meu desenvolvimento técnico como Bacharela em Engenharia de Software. 

No dia a dia escolar, a adaptação de materiais pedagógicos para alunos com necessidades específicas (como TEA e TDAH) é um desafio complexo e que demanda muito tempo dos educadores. Este assistente utiliza IA Generativa para automatizar e otimizar esse processo, transformando conteúdos didáticos tradicionais em materiais estruturados sob medida para a acessibilidade cognitiva.

### 🚀 Funcionalidades
- **Interface Intuitiva (UX):** Desenvolvida com foco na simplicidade para que profissionais da educação usem sem barreiras técnicas.
- **Engenharia de Prompt Especializada:** Instruções configuradas para reestruturar textos seguindo diretrizes neuroeducativas de ordem direta, quebra de blocos e exclusão de ambiguidades.
- **Modelagem Adaptativa:** Opções de filtragem focadas em TEA, TDAH e Simplificação Linguística Geral.

### 🛠️ Tecnologias Utilizadas
- **Front-End:** HTML5 estruturado e CSS3 responsivo.
- **Lógica e Integração:** JavaScript Assíncrono.
